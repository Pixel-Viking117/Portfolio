GameOver Scene | What Did I Learn?

I implemented a Game Over system in Unity using collision detection.

The player uses an OnCollisionEnter trigger to detect contact with enemies. If the player has no remaining lives, this triggers the Game Over state.

This system is expandable and will later be integrated into a full life-management loop.

I also created a custom pixel-art laser sound effect that plays on mouse input.
